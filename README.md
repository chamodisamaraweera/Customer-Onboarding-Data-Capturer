In this robot I built an RPA workflow that reads customer data from an Excel sheet and captures each row from that spreadsheet into both a web app CRM and desktop app CRM simultaneously. In this robot I learnt 
how to use different types of selectors (Strict, Fuzzy, Computer Vision) to identify UI elements as well as best practices for typing data into different types of fields.

### Skills gained

- Read and processed customer records from Excel using DataTables and row-by-row iteration.
- Designed modular workflows by splitting logic into multiple XAML files and invoking them with arguments.
- Automated both browser and desktop applications using Application Card, click, and type into activities.
- Used Strict, Fuzzy, and Computer Vision selectors, including anchors and dynamic selectors for unstable UIs.
- Applied best practices for text input using Type Into, Type by Clipboard, and hardware-based typing.
- Implemented control flow with If and Switch activities to handle different onboarding scenarios.
- Added robust error handling using Try Catch, Retry Scope, and ContinueOnError to make the robot resilient.
- Utilized Computer Vision activities to interact with difficult UI elements when normal selectors failed.
- Performed verification and debugging steps to confirm data accuracy and improve workflow performance.
